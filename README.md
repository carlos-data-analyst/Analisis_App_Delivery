# Analisis_App_Delivery

Proyecto de Clusterización de transacciones en app de restaurantes apoyado por Machine Learning.

Este proyecto consistió en implementar una segmentación de los clientes de una App de pedidos de comida. El análisis y desarrollo se llevó acabo a través de técnicas de ciencia de datos y algoritmos de aprendizaje automático; para este caso específico se utilizó el algoritmo de K-means proveniente del framework sklearn.

La finalidad del presente análisis fue encontrar alternativas de optimización en la operación, así como brindar "insights" para el área de Marketing y optimizar también las campañas publicitarias dentro de la app.

El flujo del proyecto se encuentra dentro del documento "Ruta del proyecto".

- Dentro de la carpeta "Data" encontrará el archivo ".csv" con la tabla concentradora de datos con los que se llevó acabo el análisis.

- Además, dentro de la carpeta "Notebook" se encuentra el archivo ".ipynb" con el código/desarrollo técnico del proyecto. Cada punto cuenta con las notas y observaciones pertinentes con la finalidad de hacer el análisis lo más explicito posible.

- Finalmente, dentro de la carpeta "Presentación ejecutiva" encontrará el PDF "Segmentacion_clientes_ejecutiva" con el resumen y hallazgos del análisis.
