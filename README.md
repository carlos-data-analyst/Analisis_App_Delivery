# Analisis_App_Delivery
Proyecto de Clusterización de transacciones en app de restaurantes apoyado por Machine Learning.

Este proyecto consistió en implementar una segmentación de los clientes de una App de pedidos de comida. 
Esto con la finalidad de encontrar alternativas de optimización en la operación, así como brindar "insights" para el área de Marketing y optimizar también las campañas publicitarias dentro de la app.
